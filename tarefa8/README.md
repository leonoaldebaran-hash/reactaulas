# Tarefa 8 - CRUD de usuários via API (crudcrud)

App feito no Expo Snack (SDK 54) que faz o CRUD de usuários (nome, telefone, endereço) consumindo a API do crudcrud.

Estrutura (seguindo a convenção do repositório):
- `apis/Apis.js`: classe com os métodos `fetch` (criar, listar, atualizar, excluir)
- `screens/usuarios/UsuariosScreen.js` + `Style.js`: tela do CRUD
- `components/`: `CustomButtom` e `TextInputBox`

Status: em andamento (passo a passo).
